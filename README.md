# CrossApp

Наскрізний проєкт з крос-платформного програмування.

Предметна область: Бібліотека.
Сутності: Book (книга), BookCopy (примірник), Reader (читач), Loan (видача).
Призначення: облік видач примірників книг читачам і повернень.

## Різниця між self-contained і framework-dependent

**Framework-dependent** публікація містить лише код застосунку (`Cli.dll`, `Core.dll`) і його залежності, без середовища виконання .NET. Каталог дуже малий, але на машині користувача має бути встановлений сумісний .NET Runtime. Якщо його немає, застосунок не запуститься.

**Self-contained** публікація містить код застосунку разом із копією .NET Runtime. Застосунок працює на комп'ютері без встановленого .NET, але каталог значно більший (76.85 МБ, 194 файли).

## Запуск
dotnet build
dotnet run --project src/Cli

# publish: self-contained
dotnet publish src/Cli -c Release -r win-x64 --self-contained true -o out/sc

# publish: framework-dependent
dotnet publish src/Cli -c Release -r win-x64 --self-contained false -o out/fd

# запуск із каталогу publish
./out/sc/Cli.exe
./out/fd/Cli.exe

----------------------------------------------------------------------------------
| RID     | Режим               | Розмір publish | Потрібен встановлений runtime |
|---------|---------------------|----------------|-------------------------------|
| win-x64 | self-contained      | 76.85 МБ       | ні                            |
| win-x64 | framework-dependent | 0.19 МБ        | так (.NET 10)                 |

## Середовище
.NET SDK 10.0, Windows 11 x64

## Інваріанти системи

### 1. Інваріанти BookCopy (примірник книги)

- Ідентифікатор примірника не може бути порожнім.
- ISBN, назва та жанр книги не можуть бути порожніми.
- Рік видання повинен бути коректним.
- Не можна видати примірник, який уже виданий.
- Не можна повернути примірник, який не був виданий.

### 2. Інваріанти Loan (видача книги)

- Ідентифікатор видачі та читача не можуть бути порожніми.
- Видача повинна бути пов'язана з конкретним примірником книги.
- Дата повернення не може бути ранішою за дату видачі.
- Закрити можна лише відкриту видачу.
- Позначити книгу втраченою можна лише для відкритої видачі.
- Закриту або втрачену видачу не можна повторно закрити.

### 3. Інваріанти LoanService

- Один читач не може мати більше 5 відкритих видач одночасно.
- Перед новою видачею сервіс перевіряє кількість відкритих видач читача.
- Якщо читач уже має 5 відкритих видач, створення шостої забороняється.


Інтерфейс сховища: `ILibraryStore`.

Реалізації:

- `InMemoryLibraryStore` — зберігання в пам'яті;
- `FileLibraryStore` — зберігання у JSON-файлі.

Сервіс `LendingService` отримує сховище через конструктор.

Запуск у режимі пам'яті:

    dotnet run --project src/Cli

Запуск у файловому режимі:

    dotnet run --project src/Cli -- --file
